# Liberty Unquenched

Political simulation game set in the Second Spanish Republic, playing as the CNT-FAI.

The local version is the source of truth. GitHub Actions builds `main` and publishes the result to `gh-pages`.

## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies: `npm ci`
2. Start the app: `npm run dev`

No Gemini API key or other secret is required.
